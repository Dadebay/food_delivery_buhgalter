# accounting_app

Мобильный просмотр бухгалтерии: смены, месяц и контроль действий.

Клиент **только для чтения** поверх `https://a7-tagam.com.tm/api/v1`, раздел
`accounting`. Он показывает то, что посчитал сервер, и ничего не считает
заново: суммы, статусы и история берутся из ответов API.

Доступ — активные `ACCOUNTANT` и `SUPER_ADMIN`. Бухгалтер может подтвердить
переданный денежный пакет; создание пакета и любое редактирование заказов
остаются вне этого приложения.

Спецификация: `ACCOUNTING_OVERSIGHT_MOBILE.md`.

## Запуск

```
flutter pub get
flutter run
```

Проект ответвлён от `SMS_OTP_get_post_method` — тот же стек (GetX,
get_storage, http, шрифты Gilroy).
